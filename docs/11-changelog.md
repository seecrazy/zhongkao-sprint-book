## v1.3.1 - 2026-11-10

听力音色修正：Multilingual Copilot 音色 → 播音级经典音色 Guy + Aria。

### Fixed

- 用户实测反馈 v1.3 的 Andrew/Ava Multilingual 音色"跟真人差距还挺大"，且明显不如 oralenglishmaster 项目的人声自然。
- **时长指纹法锁定根因**：oralenglishmaster 的 1479 段音频同为 edge-tts 生成（48kbps/24kHz/mono 格式特征一致），用同一句台词对比各候选音色的合成时长，原版男声 4.66s 最接近 GuyNeural（4.44s），女声 3.74s 最接近 AriaNeural（3.29s）；而被否决的 Ava 系仅 2.06s——语速急促 1.6 秒，韵律生硬。
- **结论**：Multilingual 系 Copilot 音色为多语言通用优化，英语韵律反而急促；Guy/Aria 是微软打磨最久的新闻/播音级音色，语速从容、最接近真人对话听感。
- 全部 41 段听力音频用 **GuyNeural（男）+ AriaNeural（女）** 重新生成；SW 缓存版本 bump 使客户端旧音频缓存失效。
- 教训已写入项目记忆：英语人声首选 Guy + Aria/Jenny，慎用 Multilingual 系。

## v1.3.0 - 2026-11-10

- **神经网络语音预生成**：用微软 Edge Neural TTS（`edge-tts`，与 Edge 浏览器"大声朗读"同源的神经网络引擎）离线合成全部 20 道听力题共 41 段 MP3（男声 Andrew / 女声 Ava，Copilot 对话音色），总计仅 932KB，随应用静态分发——纯静态架构、零运行时依赖、无 API Key。

- 播放中新增"■"停止按钮；听力题不再依赖浏览器是否支持 SpeechSynthesis（不支持 TTS 的环境也可播音频）。

## v1.2.0 - 2026-11-10

## v1.2.0 - 2026-11-10

听力音质升级：语音质量评分选声、男女分声对话朗读、音色选择器与连读两遍。

### Changed - 朗读音质（"机器人味"根治）

- **语音质量评分选声**：Premium / Enhanced / Natural / Neural / Siri 一档（+60），Google / Microsoft Online 现代语音一档（+30），macOS 具名声一档（+18）；Compact / Desktop / 旧版 "Microsoft Zira - English" 横杠命名 / 搞怪音（Bubbles、Zarvox 等）重罚淘汰（-50）。旧逻辑优先挑本地 en-US 语音，在 Chrome/macOS 上会命中紧凑版系统语音——这是"机器人味"的主要来源。
- **说话人标签不再被朗读**：听力脚本的 `M:` / `W:` / `Man:` / `女：` 等标签在播放时自动剥离（此前 "M""W" 会被当作单词读出来）；连续同说话人的回合自动合并；普通含冒号文本（如 "The meeting time: 9 a.m."）不会误判。
- **男女分声**：对话按说话人自动分配不同音色（按评分挑选男女声，如 Samantha + Fred）；缺少对应性别音色时用同一音色 + 音调区分（男 0.95 / 女 1.08）。
- **自然停顿**：句间 160ms、说话人切换 480ms、两遍之间 900ms。
- **连读两遍（考试模式）**：听力题新增"▶▶ 连读两遍"按钮，对齐中考"每段材料读两遍"的真实节奏。

### Added - 音色选择器

- 设置页「英语听力朗读」新增音色下拉：列出系统全部英语音色并标注质量档（高清 / 良好 / 基础）与语言，默认"自动（按质量挑最佳）"，选择后持久化并对所有听力题生效。
- 「▶ 试听对话」用当前音色朗读一段男女对话（同时验证分声效果），「■ 停止」可随时打断。
- 附安装更好语音的系统指引：macOS 系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理语音（安装 Enhanced/Premium 声音）；Windows 设置 → 时间和语言 → 语音。本机未装增强语音时，这是提升自然度的最有效途径。

### Technical

- `src/lib/tts.ts` 全面重写：`scoreVoice` / `rankEnglishVoices` / `guessVoiceGender` / `parseDialogue` / `pickDialogueVoices` 均为纯函数可测；播放器改为会话制顺序队列（`stopSpeaking` 立即取消）。
- 播放选项支持 `forceVoiceURI`（设置页指定音色）与 `times: 1 | 2`（连播遍数）。
- 测试 64 → 75 个（+语音评分排序 / 性别推断 / 对话解析含中文标签与误判防护 / 双声挑选）。
- 浏览器实测：本机 42 个英语音色正确排序标注，试听真实发声，男女分声对话播放通过。

## v1.1.0 - 2026-11-10

## v1.1.0 - 2026-11-10

全量补强版：表达式等价判分、作文与主观题本地评分、英语听力 TTS 方案、运行时 Schema 校验。

### Added - 表达式等价判分

- 新增零依赖表达式引擎 `src/lib/expression.ts`：tokenizer + 递归下降解析 + 求值（一元代数式，支持隐式乘法 `2x`、`3(x+1)`、`(x+1)(x-1)`、幂运算、一元负号、全角/×÷ 归一）。
- 等价判断采用采样法：在 10 个无理数采样点比较函数值（相对容差 1e-9），除零点自动跳过；无法解析返回 null 并降级为文本精确匹配，绝不"猜对"。
- 表达式题新增 `answerKind: "algebraic"`：`(x+1)(x-1)`、`x*x-1`、`y=x^2-1` 均判等价于 `x^2-1`。

### Added - 作文与主观题评分（本地可解释）

- 新题型 `essay`（作文题）：题干含文体/字数要求、写作要点、评分量表（内容与情感 20 / 结构与条理 15 / 语言与表达 10 / 书写与规范 5，中考 50 分制）。
- 双轨评分：系统自动分析（字数、段落数、过渡词命中）+ 学生按量表逐维度自评；字数达 90% 且自评 ≥80% 判通过，得分与错题流程全链路接入。
- 作文编辑器：实时字数、三段结构提示、自评量表点选（修复 React 批处理下连续点选相互覆盖的 bug——latest-ref 同步合并）。
- 新题型 `short-answer`（短答/翻译题）：按要点命中给分，部分正确得部分分；要点支持 `patterns`（命中词）与 `notPatterns`（禁用词，如"不得使用'安静'一词"），匹配忽略大小写/空白/标点。
- 语文新考点「写作与表达」（high）：12 道作文题（记叙文 8 / 议论文 2 / 材料作文 2）+ 8 道片段写作（仿写/扩写/开头结尾/病句修改/提纲），含结构化讲解（审题立意/结构布局/细节描写）。
- 文言文翻译题 6 道：《论语》《桃花源记》《出师表》《小石潭记》《岳阳楼记》《醉翁亭记》经典句翻译，按实词/句式要点给分。

### Added - 英语听力（TTS 方案）

- 新增 `src/lib/tts.ts`：浏览器原生 SpeechSynthesis 朗读引擎（零依赖、离线可用），自动挑选英语语音、长文本按句切分、语速三档（慢速 0.7 / 标准 0.85 / 常速 1.0）独立持久化，设置页可试听。

- 英语新考点「听力理解」（high）：15 道短对话单选（天气/问路/购物/时间计算/改主意等中考高频场景）+ 5 道听句填空（动词短语/时间短语），含结构化讲解（预读预测/关键词速记/同义转换）。

- 新增每日冲刺计划。
- 根据到期错题和薄弱考点生成复习、专项、模考和复盘任务。
- 每日任务支持标记完成并保存到本地。
- 新增限时模考页面。
- 新增倒计时、答题卡、上一题 / 下一题和立即交卷。
- 时间归零后自动交卷。
- 未完成模考支持暂离保存。
- 交卷后生成总分、得分率、用时和分考点报告。
- 报告页展示逐题结果、解析、常见错误和更优方法。
- 新增最近 20 次模考成绩历史。
- 外置试卷文件 `math-exams.json`。
- 新增第一套数学基础冲刺摸底卷：15 题、25 分钟、总分 15 分。

### Improved

- 数学题库扩展到 11 个知识点、25 道题。
- 难度分布扩展为基础 14、中等 9、较难 2。
- 所有 11 个考点均达到当前覆盖率结构健康标准。
- 修正正确题判分结果中 `score` 始终为 0 的问题。
- 内容校验支持试卷字段、试卷 ID、试卷题目引用和重复题目检查。
- 设置页清空进度时同时清空模考会话和模考历史。

### Content

- 新增统计、因式分解、全等三角形、相似三角形、一元二次方程和二次函数题目。

### Technical

- 版本号升级到 `0.4.0`。
- 新增 `src/lib/planner.ts`、`src/lib/exam.ts`、`src/lib/exam-storage.ts` 和 `src/pages/Exam.tsx`。
- 本地通过 `validate:content`、`report:coverage`、`typecheck` 和 `build`。

## v0.3.0 - 2026-10-31

### Added

- 新增 `src/lib/mastery.ts` 掌握度引擎。
- 记录每次作答状态、用户答案和用时。
- 计算单题连续答对次数和平均用时。
- 计算考点覆盖率、正确率、稳定性、综合掌握度。
- 首页展示综合掌握度、今日做题、连续学习、到期错题和累计用时。
- 考点地图展示覆盖率、正确率、稳定性和掌握度。
- 新增错题间隔复习队列。
- 错题本支持到期复习、全部错题、已掌握筛选。
- 新增复习模式，可一键复习到期错题。
- 表达式题新增 `answerKind`，支持解集判分和精确文本判分。
- 新增内容覆盖率报告脚本 `report:coverage`。
- 数学内容扩展到 11 个知识点、19 道题。
- 抽离独立 `QuestionCard` 组件。

### Improved

- 错题复习阶段支持当天、1 天、2 天、4 天、7 天、15 天间隔。
- 连续答对可推进复习阶段，再错会重置。
- 本地进度升级为 v0.3 结构，并兼容读取 v0.1 旧数据。
- 内容校验支持 `answerKind`，并检查选项和解析中的公式定界符。
- TypeScript 编译目标升级到 ES2022。

### Content

- 新增实数与运算、整式与因式分解、一元一次不等式、二次函数、全等三角形、相似三角形和概率初步题目。
- 所有 11 个数学知识点均有题目覆盖。

### Technical

- 版本号升级到 `0.3.0`。
- 本地通过 `validate:content`、`report:coverage`、`typecheck` 和 `build`。
