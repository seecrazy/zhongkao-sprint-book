# 设计文档：电学扩容 · 电路图 · 作图题 · 实验题（v0.17）

状态：已定稿，按本设计实现。

## 1. 目标

1. 电学考点补齐：新增"电路与电路图"（high）、"家庭电路与安全用电"（medium）、"电与磁"（medium）三个考点，全部带结构化讲解。
2. 电路图支持：题目新增可选 `diagram` 字段（Unicode 字符画，`<pre>` 等宽渲染），新增题目包含真实电路图（串并联识别、开关影响、伏安法测电阻电路等）。
3. 作图题（对齐中考）：`displayType: "作图题"`，题目给出底图与作图要求，用户在纸上作图后**对照参考答案自评**（单选"已完成/未完成"零引擎改动，解析含参考作图）。
4. 实验题：`displayType: "实验题"`，覆盖伏安法测电阻、测固体密度、测灯泡电功率（判断 + 填空 + 选择）。
5. 物理试卷蓝图升级为六区（对齐真实中考）：单选 11×2 · 多选 2×3 · 填空 8×2 · 作图 2×2 · 实验探究 2×3 · 计算 4 题 [7,8,10,11]，共 90 分 / 90 分钟。
6. 生成器题池合并手写题：模拟卷组卷覆盖手写题 + 生成题全池。

## 2. 非目标

- 不做图片渲染的电路图/作图评分（字符画 + 自评为本期方案）；不做听力。

## 3. 边界与错误处理

- `diagram` 为可选字段，不参与校验；作图题为单选自评，成绩如实记录为自评结果。
- 生成器题池合并后，手写题 ID 不变；生成 ID 前缀 `gen-` 不冲突。
