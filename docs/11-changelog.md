# Changelog

## v0.12.0 - 2026-11-01

### Added

- 新增英语试点学科：5 个考点（动词时态、被动语态、从句基础、词汇辨析、情景交际），全部带结构化讲解。
- 新增语文试点学科：5 个考点（字音与字形、词语与成语运用、病句辨析、古诗文默写、文学文化常识），全部带结构化讲解。
- 两学科各含 16 道题（单选 + 词形填空 / 补全默写），各含 2 套卷（基础摸底卷 + 薄弱考点精准卷）。
- 学科切换器五学科全部上线（数学 / 物理 / 化学 / 英语 / 语文）。

### 边界说明

- 英语当前覆盖语法、词汇和书面交际，听力音频暂不包含。
- 语文当前覆盖积累运用（客观题），作文与阅读主观题暂不包含。

### Content

- 新增 `english.json`（`english-v0.12`）/ `english-exams.json`、`chinese.json`（`chinese-v0.12`）/ `chinese-exams.json`。
- 全库达到 42 个考点、133 道题、14 套试卷。

### Technical

- `Subject` 类型扩展 `chinese`。
- 版本号升级到 `0.12.0`。
- 本地通过 `validate:content`、`report:coverage`（题目覆盖 42/42，结构健康 42/42）、`test`（16 个测试）、`typecheck` 和 `build`。

## v0.8.0 - 2026-11-01

### Added

- 新增 6 道几何压轴题（难度 4），每个题型对应一个中考经典模型：
  - 相交线与平行线：平行线拐点模型。
  - 四边形：菱形面积双算求高（结合勾股）。
  - 圆：平行弦与垂径定理（结合勾股）。
  - 直角三角形：周长与斜边求面积（勾股 + 完全平方）。
  - 相似三角形：母子相似模型（$AC^2 = AD \\cdot AB$）。
  - 图形变换：平移 + 对称 + 平移三步变换链。

### Improved

- 压轴题提速挑战卷几何分区从 3 题扩展到 6 题，整卷升级为 11 题 / 25 分钟 / 总分 22。

- 当前内容包含 16 个知识点、16 份考点讲解、46 道题、4 套试卷。
- 较难题从 2 道增加到 8 道，每个几何考点均有压轴层级题目。
