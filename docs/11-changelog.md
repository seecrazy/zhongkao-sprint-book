# Changelog

## v0.8.0 - 2026-11-01

### Added

- 新增 6 道几何压轴题（难度 4），每个题型对应一个中考经典模型：
  - 相交线与平行线：平行线拐点模型。
  - 四边形：菱形面积双算求高（结合勾股）。
  - 圆：平行弦与垂径定理（结合勾股）。
  - 直角三角形：周长与斜边求面积（勾股 + 完全平方）。
  - 相似三角形：母子相似模型（$AC^2 = AD \\cdot AB$）。
  - 图形变换：平移 + 对称 + 平移三步变换链。

### Improved

- 压轴题提速挑战卷几何分区从 3 题扩展到 6 题，整卷升级为 11 题 / 25 分钟 / 总分 22。

### Content

- 数学内容版本升级到 `math-v0.8`。
- 试卷内容版本升级到 `math-exams-v0.8`。
- 当前内容包含 16 个知识点、16 份考点讲解、46 道题、4 套试卷。
- 较难题从 2 道增加到 8 道，每个几何考点均有压轴层级题目。

### Technical

- 版本号升级到 `0.8.0`。
- 本地通过 `validate:content`、`report:coverage`、`test`（16 个测试）、`typecheck` 和 `build`。
- 题目覆盖 16/16，结构健康 16/16。
