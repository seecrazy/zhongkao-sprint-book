# Changelog

## v0.3.0 - 2026-10-31

### Added

- 新增 `src/lib/mastery.ts` 掌握度引擎。
- 记录每次作答状态、用户答案和用时。
- 计算单题连续答对次数和平均用时。
- 计算考点覆盖率、正确率、稳定性、综合掌握度。
- 首页展示综合掌握度、今日做题、连续学习、到期错题和累计用时。
- 考点地图展示覆盖率、正确率、稳定性和掌握度。
- 新增错题间隔复习队列。
- 错题本支持到期复习、全部错题、已掌握筛选。
- 新增复习模式，可一键复习到期错题。
- 表达式题新增 `answerKind`，支持解集判分和精确文本判分。
- 新增内容覆盖率报告脚本 `report:coverage`。
- 数学内容扩展到 11 个知识点、19 道题。
- 抽离独立 `QuestionCard` 组件。

### Improved

- 错题复习阶段支持当天、1 天、2 天、4 天、7 天、15 天间隔。
- 连续答对可推进复习阶段，再错会重置。
- 本地进度升级为 v0.3 结构，并兼容读取 v0.1 旧数据。
- 内容校验支持 `answerKind`，并检查选项和解析中的公式定界符。
- TypeScript 编译目标升级到 ES2022。

### Content

- 新增实数与运算、整式与因式分解、一元一次不等式、二次函数、全等三角形、相似三角形和概率初步题目。
- 所有 11 个数学知识点均有题目覆盖。

### Technical

- 版本号升级到 `0.3.0`。
- 本地通过 `validate:content`、`report:coverage`、`typecheck` 和 `build`。

## v0.2.0 - 2026-10-31

### Added

- 引入 KaTeX 数学公式渲染。
- 新增 `MathText` 组件。
- 将数学知识点和题目外置到 `src/data/math.json`。
- 添加内容校验脚本 `validate:content`。
- 添加 URL Hash 路由，刷新后可保留页面。
- 表达式题增加解集判分基础版。
- 练习页增加“再练一组”。

### Improved

- 数学题干、选项、答案、解析和常见错误支持公式显示。
- 错题本支持公式显示。
- 内容校验可发现重复 ID、缺失字段、无效引用和公式定界符错误。

### Technical

- 更新版本号为 `0.2.0`。
- 本地通过 `validate:content`、`typecheck` 和 `build`。
