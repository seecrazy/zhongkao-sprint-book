# 产品概览

## 名称

- 中文产品名：中考冲刺书
- 英文 / 代码名：SprintBook
- 仓库名：zhongkao-sprint-book

## 一句话定位

中考冲刺书是一个面向初三学生的互动复习与冲刺训练平台。

## 目标用户

1. 初三学生。
2. 需要陪练和监督的家长。
3. 需要布置针对性练习的老师或辅导机构。

## 核心问题

学生在冲刺阶段常见的问题是：

```text
不知道自己哪里薄弱
→ 盲目刷题
→ 错题反复错
→ 缺少复盘和复习计划
```

## 产品目标

1. 帮学生定位薄弱考点。
2. 按考点组织专题训练。
3. 提供即时判分和解析。
4. 自动记录错题。
5. 根据错误率和掌握度推荐练习。
6. 支持整卷模考和试卷分析。

## 学习闭环

```text
考点诊断
  ↓
专题练习
  ↓
一键判分
  ↓
答案解析 / 更优解法
  ↓
错题本
  ↓
间隔复习
  ↓
掌握度更新
```

## MVP 范围

当前 MVP 已完成数学试点的基础闭环：

1. 基础页面框架。
2. 数学知识点与题库内容外置。
3. 单选题、数值题、表达式题。
4. 一键判分、公式渲染和解析展示。
5. 本地错题本。
6. 做题记录、用时记录和考点掌握度。
7. 错题间隔复习。
8. localStorage 进度保存。

## 非目标

以下内容当前不做：

- 账号系统；
- 云端同步；
- 社交排名；
- 完整全科题库；
- 模考整卷；
- AI 作文批改；
- 家长端小程序。
