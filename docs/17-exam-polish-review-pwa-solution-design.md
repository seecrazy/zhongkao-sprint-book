## 一、模拟卷精修（真实中考蓝图）

### 目标
为五科模拟卷定义参考真实中考的卷面蓝图（科目 → 满分 / 时长 / 分区题序 / 题型 / 每题分值），重新组装 50 套模拟卷；解答区内按难度升序排题，大题分值递增。

### 蓝图（满分 / 时长 / 分区）

```text
数学 120 分 / 120 分钟：一、单选 10×3；二、填空 5×4；三、解答 8 题 [6,6,8,8,10,10,10,12]
物理 90 分 / 90 分钟：一、单选 12×2；二、多选 3×3；三、填空 8×2；四、计算与实验 5 题 [7,7,8,8,11]
化学 80 分 / 60 分钟：一、单选 12×2；二、填空 6×3；三、实验探究 3 题 [6,6,6]；四、计算 2 题 [10,10]
英语 100 分 / 100 分钟：一、语法选择 20×1；二、词形填空 15×2；三、情景交际 10×2；四、词汇运用 10×3
语文 120 分 / 120 分钟：一、积累运用 15×2；二、默写 10×2；三、文言文 8×3；四、文学常识 8×2；五、语言运用 10×3
```

### 降级规则
某分区题池不足时按 `floor(池/卷数)` 缩减题量并在卷面描述中如实标注；总分按实际题量重算。

### 验收
- [x] 50 套卷全部按蓝图题序与分值重组，描述含满分与结构（题池不足的分区按设计降级并在描述标注）。

## 二、错题变式重练

### 目标
错题按既有间隔复习到期后，可进入"变式重练"：用同考点、同题型的**另一道题**替代原错题作答，避免背答案。

### 交互
- 错题本新增"变式重练"入口 → `practice?review=1&variant=1`。
- 练习页在变式模式下，把每道到期错题替换为同考点同题型的其他题目（优先生成题），页首提示当前模式。

### 边界
- 无可替换题目时回退原错题。

### 验收
- [x] 变式模式下作答的题目与原错题同考点同题型但 ID 不同。

## 四、多步题与步骤分（solution 题型）

### 数据模型

```ts
interface SolutionStep {
  prompt: string;            // 步骤提示（如"求拉力做的功"）
  type: "numeric";           // 第一版步骤答案仅支持数值
  answer: number;
  tolerance?: number;
  score: number;             // 步骤分
}
interface SolutionQuestion extends BaseQuestion {
  type: "solution";
  steps: SolutionStep[];     // ≥2 步
}
```

### 判分
作答值为步骤答案的 JSON 数组；每步独立判分，得分 = 通过步骤分之和；全对 → correct，部分对 → wrong（score>0），全空 → skipped。

### 交互
答题卡按步骤渲染提示 + 输入框；反馈区逐步骤显示对错与正确答案。

### 内容
生成器新增解答题多步模板：数学解方程（判别式 / 两根）、物理功与功率 / 电能与电功率、化学方程式两问计算，约 40 道，difficulty 4。

### 校验
`type: "solution"`：steps ≥ 2，每步 score ≥ 1 且 answer 为有限数值。

### 实现期修订
- 内容校验器的"分区 ≥3 题"规则与真实中考卷面冲突（如计算大题仅 2 题、按分值分组的小节可能 1~2 题），已放宽为"分区 ≥1 题"。

### 验收
- [x] 步骤分累加正确；部分步骤正确时 score > 0 且 status = wrong（生成解答多步题 36 道）。
