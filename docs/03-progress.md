# 项目进展

最后更新：2026-10-31  
当前阶段：v0.2 数学试点完成，内容外置、公式渲染、Hash 路由与表达式解集判分已通过本地验证

## 当前摘要

项目已完成 v0.2 本地迭代。示例内容已经外置到 JSON，数学题干和解析可使用 KaTeX 渲染；页面支持 Hash 路由；表达式题已能按解集判分。内容校验、类型检查和生产构建均已通过。

当前已经跑通：

```text
选择考点
→ 作答单选题 / 数值题 / 表达式题
→ 一键打分
→ 查看解析和更优方法
→ 错题进入本地错题本
→ 完成题写入本地进度
```

当前还支持：

```text
刷新后保留页面位置
数学公式渲染
同一解集的不同书写形式判对
内容 JSON 自动校验
```

2. 表达式判分已支持解集比较，但还不是完整数学表达式等价判断。
3. 内容加载仍使用 TypeScript 类型断言，后续应增加运行时 Schema 校验。
4. 错题本还只有基础记录，缺少错因分类和间隔复习。
5. KaTeX 全量 CSS 和字体使构建产物增大，后续可按需优化。
