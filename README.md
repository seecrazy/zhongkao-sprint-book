# 中考冲刺书 · SprintBook

一个面向中考冲刺阶段的互动练习平台。当前项目处于 **v1.1.0 全量补强版**：五科 59 个考点 / 1536 道题（每考点 ≥20 题）/ 64 套卷（每科 10 套模拟卷），题型覆盖单选 / 多选 / 数值 / 表达式 / 解答题（多步步骤分）/ 短答翻译（要点给分）/ 作文（量表自评）。v1.1 新增：表达式等价判分、作文与主观题本地评分、英语听力（浏览器 TTS 朗读，零音频文件）、运行时 Schema 校验；v1.0 已有：中考倒计时与三轮冲刺计划、错因治理、分题型分析、深色模式、判分容错（分数 / 科学计数法 / 单位 / 全角）、PWA 离线与错题变式重练。

## 产品定位

> 考点看得清，错题改得掉，冲刺有计划。

SprintBook 围绕冲刺学习闭环设计：

```text
中考倒计时与阶段判断
→ 阶段感知每日计划
→ 考点讲解
→ 薄弱考点专项
→ 错题间隔复习（错因治理）
→ 分区限时模考
→ 自动判分与报告（分区 / 分题型 / 分考点）
→ 掌握度与趋势更新
→ 本周学习报告
```

## 当前版本特性

### 冲刺驾驶舱（v1.0）

- 设置中考日期后，首页显示倒计时与阶段徽章。
- 三轮冲刺阶段模型：距考 >90 天为一轮基础期（优先读讲解），31～90 天为二轮专项期（薄弱考点突破），≤30 天为三轮冲刺期（整卷节奏 + 错题清零）。
- 每日计划按阶段自动调整：基础期加入"通读讲解"任务，冲刺期专项训练收敛为 1 个最弱考点。
- 本周学习报告：近 7 天作答量、正确率、活跃天数与用时，含环比上周对比。

### 每日冲刺

- 根据到期错题、薄弱考点和模考可用性生成今日任务。
- 支持错题复习、专项训练、限时模考和复盘任务。
- 任务完成状态按日期保存在本地。

### 题型与判分

- 单选题、多选题（全对才得分）、数值题（支持容差）、表达式题（解集 / 中英文填空 / **代数等价 v1.1**）、解答题（多步步骤分）、**短答翻译题（要点给分 + 禁用词，v1.1）**、**作文题（量表自评 + 自动分析，v1.1）**。
- 数值判分容错（v1.0）：支持分数（`3/4`）、科学计数法（`1.2e3`、`1.2×10³`）、尾部单位（`25 N`）、全角字符与千分位逗号。
- 代数等价判分（v1.1）：零依赖解析引擎按采样点比较函数值，`(x+1)(x-1)`、`x*x-1`、`y=x^2-1` 均等价于 `x^2-1`。
- 模考中解答题按步骤得分比例折算分区分值，部分正确得部分分。

### 专题与掌握度

- 数学 16 考点 / 46 题 / 4 卷 + 物理 8 考点 / 27 题 / 3 卷 + 化学 8 考点 / 28 题 / 3 卷 + 英语 5 考点 / 16 题 / 2 卷 + 语文 5 考点 / 16 题 / 2 卷。
- 每个考点提供结构化讲解：学习目标、核心思路、概念、公式、例题、易错警示和解题策略，公式由 KaTeX 渲染。
- 讲解阅读状态：可标记"已读"，考点地图显示讲解覆盖率。
- 记录每题状态、答案和用时；计算覆盖率、正确率、稳定性、加权掌握度（含时间衰减与难度调整）。
- 分题型掌握度（v1.0）：考点卡片展示每种题型的正确率，定位"同考点某题型特别弱"。
- 考点地图按掌握度展示薄弱优先级。

### 学科切换

- 导航栏一键切换数学 / 物理 / 化学 / 英语 / 语文。
- 学习进度、错题本、模考记录按学科独立保存，互不干扰。
- 路由带学科前缀：`#/math/practice`、`#/physics/exam`，旧链接自动兼容。

### 真实中考体验（v0.16）

- 模拟卷蓝图精修：五科卷面（题序/分区/分值）对齐真实中考，如数学 120 分 = 单选 10×3 + 填空 5×4 + 解答 8 题（6~12 分递增）。
- 错题变式重练：到期错题可用同考点同类题替代作答，防止背答案。
- 解答题分步判分：解答题按步骤作答，步骤分累加，部分正确可得部分分。
- PWA 离线缓存：首次访问后断网可用，学习数据全本地。

### 速查表

- 数学 / 物理 / 化学 14 组 55 条核心原理、公式与口诀。
- 支持关键字实时检索，公式 KaTeX 渲染。
- 导航栏"速查表"入口，路由 `#/math/reference` 等。

### 限时模考

- 64 套分区试卷：每科 2 套精品卷 + 10 套冲刺模拟卷（参考真实中考卷面结构）。
- 支持倒计时、答题卡、上一题 / 下一题、立即交卷。
- 时间归零自动交卷。
- 支持未完成会话暂离保存。
- 报告包含总分、分区成绩、**分题型得分（v1.0）**、分考点成绩、冲刺建议和逐题解析。
- 最近 20 次成绩本地保存。
- SVG 趋势图展示历次得分率变化（深浅色主题下均可读）。

### 错题与复习

- 错题或未作答题自动进入间隔复习队列：当天 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天。
- 连续答对 2 次提升阶段，再错重置；支持到期复习、全部错题、已掌握筛选。
- **错因治理（v1.0）**：
  - 错因五分类：概念不清 / 计算失误 / 粗心大意 / 审题不清 / 未归类；
  - 判分时自动标注初判错因，可在错题卡片下拉手动修正；
  - 错因分布面板按错因计数并一键筛选；
  - 手动"标记已掌握"立即退出复习队列；
  - 支持打印当前错题列表（打印视图隐藏界面控件，仅保留题目内容）。

### 外观（v1.0）

- 深色模式：导航栏一键切换跟随系统 / 浅色 / 深色，或设置页选择；偏好全局保存。
- 全站样式基于语义化 CSS 变量，深浅两套主题完整覆盖。

### 工程质量

- 64 个 Vitest 测试，覆盖判分（数值解析器 / 表达式等价 / 要点判分 / 作文自评）、考点讲解结构、题库引用、分区与分题型评分、趋势、掌握度衰减、复习调度、错因治理、冲刺阶段、周报、阶段感知计划、TTS 与运行时 Schema。
- 内容校验、覆盖率报告、单元测试已纳入 GitHub Actions。
- TypeScript strict 类型检查。

## 掌握度算法

单题先计算时间加权正确率：

```text
3 天内：权重 1
4～7 天：权重 0.8
8～14 天：权重 0.55
15～30 天：权重 0.3
30 天以上：权重 0.12
```

考点层再做难度调整：

```text
难度调整 = 平均((难度 - 3) × 4%)
加权表现 = 时间加权正确率 + 难度调整
```

考点掌握度：

```text
掌握度 =
  加权表现 × 50%
+ 覆盖率 × 25%
+ 稳定性 × 10%
+ 近期练习量 × 15%
```

状态阈值：

```text
0%        未开始
1%～64%   学习中
65%～84%  较稳
85%+      已掌握
```

## 当前边界

当前版本还不包含：

- 完整中考题库；
- 符号级（CAS）数学等价判断（当前为代数式采样等价，覆盖中考范围）；
- 几何图形交互题；
- 尺规作图；
- 作文 / 主观题 AI 评分（当前为本地可解释评分：量表自评 + 要点判分，无后端）；
- TTS 朗读音色依赖浏览器/系统内置语音，无真人录音；
- 云端账号与多端同步。
