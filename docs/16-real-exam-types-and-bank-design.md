# 设计文档：真实中考题型与规模化题库（v0.15）

状态：已定稿，按本设计实现。实现中设计变化先回写本文档。

## 1. 背景与目标

用户要求：题型对齐真实中考（不能只有选择/填空，要有解答题/应用题）；每科试卷 ≥10 套；每个考点专题练习 ≥20 题且覆盖所有题型。

手写千题不现实，采用**题库生成器**方案（行业通行做法）：

1. **解答题/应用题**：新增 `displayType`（解答题 / 计算题 / 应用题 / 证明题），题干含完整题目，用户输入最终答案（数值或表达式），解析中给出中考风格分步解答过程，过程可对照自评。判分复用 numeric / expression 引擎，零引擎改动。
2. **参数化数字变式**：对计算类考点（方程、函数、几何计算、物理公式计算、化学计算）用带种子的确定性生成器产出数字变式题，答案与分步解析由模板同步计算，保证正确性。
3. **知识点事实表出题**：对概念/知识类考点（元素符号、化合价、文学常识、英语词形、名句默写等）维护事实对表格，自动生成单选题 / 判断题 / 多选题 / 填空题。
4. **试卷矩阵**：每科从扩充后的题池按真实中考卷面结构（选择 / 填空 / 解答分区与分值）组装 ≥10 套卷。

### 非目标

- 不做手写作文评分、听力音频、真实图片作图题（作图题以判断/选择形式覆盖知识点）。
- 不追求生成题的文学性，计算变式题允许"数字不同、模型相同"的刷题式形态。

## 2. 用户流程

1. 专题练习选择考点 → 该考点题池 ≥20 题，含单选 / 多选 / 数值 / 表达式 / 解答题。
2. 解答题作答：读题 → 在输入框填最终答案 → 提交判分 → 对照解析中的分步过程自评。
3. 限时模考选择试卷 → 每科 10 套卷，卷面结构参考真实中考（分区、分值）。

## 3. 数据与生成模型

```text
scripts/generate-question-bank.mjs
├── 事实表（每科：元素表 / 化合价 / 文学常识 / 英语词形 / 名句对 / 病句表…）
├── 计算模板（每考点 1~2 个：参数空间 + 解析生成）
├── 确定性种子 RNG（每次运行结果稳定，题目 ID 稳定）
└── 输出
    ├── src/data/{subject}-generated.json（questions: []，ID 前缀 g）
    └── 追加试卷到 src/data/{subject}-exams.json（每科 10 套）
```

- 运行时合并：`sample-content.ts` 将 `{subject}-generated.json` 的 questions 并入学科题池。
- 校验：`validate-content.mjs` 允许"仅含 questions"的数据文件（生成题库）；生成题 ID 全局唯一且不与手写题冲突。
- 数量目标：每考点生成后总数 ≥20；全库约 54 考点 → ≥1080 题。

## 4. 关键交互

- 解答题在答题卡显示"解答题（填最终答案）"，反馈区展示完整分步过程。
- 试卷列表按真实中考结构显示分区与分值。

## 5. 边界与错误处理

- 生成器为确定性（固定种子），重复运行不产生新 ID、不改变已有题目内容。
- 计算模板的答案与解析由同一公式计算，杜绝"答案对但解析错"。
- 生成题不进入 `content.test.ts` 的结构测试范围（该测试只读主数据文件）。
- 覆盖率报告照常统计生成题（按文件扫描）。
