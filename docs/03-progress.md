# 项目进展

最后更新：2026-10-31  
当前阶段：v0.3 数学试点完成，掌握度模型与错题间隔复习已接入

## 当前摘要

v0.3 已完成本地开发。项目从“内容外置 + 公式渲染 + 基础判分”，推进到“可记录学习行为 + 可计算考点掌握度 + 可安排错题间隔复习”。

现在可以支持：

```text
选择考点
→ 逐题作答
→ 一键打分
→ 记录状态、答案和用时
→ 计算题目连续答对次数
→ 计算考点正确率、覆盖率、稳定性和掌握度
→ 错题进入间隔复习队列
→ 到期错题进入复习模式
```

当前内容规模：

```text
数学知识点：11 个
数学题目：19 道
基础题：12 道
中等题：7 道
题型：单选题 9 道、数值题 6 道、表达式题 4 道
```

待补结构缺口：

1. 平均数、中位数与众数：题型单一。
2. 整式与因式分解：难度分层不足。
3. 全等三角形：难度分层不足。
4. 相似三角形：难度分层不足。

## 已知技术债

1. 掌握度是简化模型，还没有时间衰减和难度权重。
2. 表达式判分已区分解集和文本，但还不是完整数学表达式等价判断。
3. 内容 JSON 使用 TypeScript 类型断言，还没有运行时 Schema 校验。
4. KaTeX 全量字体使构建产物偏大。
5. 作答用时依赖首次输入到交卷的时间，还不能精确判断纯思考时间。
6. 错因分类还没有手动标注和自动细分。

## 下一步
