# Changelog

## v0.5.0 - 2026-10-31

### Added

- 试卷支持分区组卷，每个分区可设置独立分值。
- 新增 3 套分区试卷：基础摸底卷、薄弱考点精准卷、压轴题挑战卷。
- 模考报告新增分区成绩。
- 新增 SVG 得分率趋势图。
- 新增 `buildExamTrend` 趋势数据函数。
- 掌握度模型新增时间衰减、难度调整和近期练习量。
- 引入 Vitest 自动化测试。
- 新增 11 个业务规则测试，覆盖判分、分区评分、趋势、掌握度和复习调度。
- CI 增加内容校验、覆盖率报告和单元测试。

### Improved

- 分区试卷可对重复题目去重计分。
- 表达式归一化支持 `≥` / `<=` 方向符号。
- 模考建议同时基于分区成绩和分考点成绩生成。
- 内容校验支持分区必填字段、分区独立分值、试卷级别和题目重复检查。

### Technical

- 版本号升级到 `0.5.0`。
- `ExamPaper` 支持 `sections` 和 `level`，同时保留旧版 `questionIds` 兼容。
- `QuestionStats` 和 `TopicStats` 新增加权正确率。
- 本地通过 `validate:content`、`report:coverage`、`test`、`typecheck` 和 `build`。

## v0.4.0 - 2026-10-31

### Added

- 新增每日冲刺计划。
- 根据到期错题和薄弱考点生成复习、专项、模考和复盘任务。
- 每日任务支持标记完成并保存到本地。
- 新增限时模考页面。
- 新增倒计时、答题卡、上一题 / 下一题和立即交卷。
- 时间归零后自动交卷。
- 未完成模考支持暂离保存。
- 交卷后生成总分、得分率、用时和分考点报告。
- 报告页展示逐题结果、解析、常见错误和更优方法。
- 新增最近 20 次模考成绩历史。
- 外置试卷文件 `math-exams.json`。
- 新增第一套数学基础冲刺摸底卷：15 题、25 分钟、总分 15 分。

### Improved

- 数学题库扩展到 11 个知识点、25 道题。
- 难度分布扩展为基础 14、中等 9、较难 2。
- 所有 11 个考点均达到当前覆盖率结构健康标准。
- 修正正确题判分结果中 `score` 始终为 0 的问题。
- 内容校验支持试卷字段、试卷 ID、试卷题目引用和重复题目检查。
- 设置页清空进度时同时清空模考会话和模考历史。

### Content

- 新增统计、因式分解、全等三角形、相似三角形、一元二次方程和二次函数题目。

### Technical

- 版本号升级到 `0.4.0`。
- 新增 `src/lib/planner.ts`、`src/lib/exam.ts`、`src/lib/exam-storage.ts` 和 `src/pages/Exam.tsx`。
- 本地通过 `validate:content`、`report:coverage`、`typecheck` 和 `build`。

## v0.3.0 - 2026-10-31

### Added

- 新增 `src/lib/mastery.ts` 掌握度引擎。
- 记录每次作答状态、用户答案和用时。
- 计算单题连续答对次数和平均用时。
- 计算考点覆盖率、正确率、稳定性、综合掌握度。
- 首页展示综合掌握度、今日做题、连续学习、到期错题和累计用时。
- 考点地图展示覆盖率、正确率、稳定性和掌握度。
- 新增错题间隔复习队列。
- 错题本支持到期复习、全部错题、已掌握筛选。
- 新增复习模式，可一键复习到期错题。
- 表达式题新增 `answerKind`，支持解集判分和精确文本判分。
- 新增内容覆盖率报告脚本 `report:coverage`。
- 数学内容扩展到 11 个知识点、19 道题。
- 抽离独立 `QuestionCard` 组件。

### Improved

- 错题复习阶段支持当天、1 天、2 天、4 天、7 天、15 天间隔。
- 连续答对可推进复习阶段，再错会重置。
- 本地进度升级为 v0.3 结构，并兼容读取 v0.1 旧数据。
- 内容校验支持 `answerKind`，并检查选项和解析中的公式定界符。
- TypeScript 编译目标升级到 ES2022。

### Content

- 新增实数与运算、整式与因式分解、一元一次不等式、二次函数、全等三角形、相似三角形和概率初步题目。
- 所有 11 个数学知识点均有题目覆盖。

### Technical

- 版本号升级到 `0.3.0`。
- 本地通过 `validate:content`、`report:coverage`、`typecheck` 和 `build`。
