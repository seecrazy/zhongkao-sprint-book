# UI / UX 设计

## 设计原则

1. 学生把时间花在思考题目上，不是研究网站。
2. 手机端体验优先。
3. 反馈必须具体，不只说“错误”。
4. 解析默认不提前暴露。
5. 页面层级清晰：题干、作答区、反馈区分离。

## 复习状态

```text
待复习：到期，需要立即复习。
巩固中：还未到期，当前处于某个复习阶段。
已掌握：连续答对 3 次且复习阶段达到 3。
```

## 每日冲刺计划

首页按当前学习状态生成任务：

```text
到期错题 → 复习任务
薄弱考点 → 专项训练任务
题库可用 → 限时模考任务
每日固定 → 复盘任务
```

任务卡片包含：

```text
任务类型
任务标题
建议做法
建议题量
开始按钮
标记完成按钮
```

完成状态按日期保存在本地。

## 移动端规则

1. 按钮高度不低于 42px。
2. 选项点击区域要大。
3. 避免横向滚动。
4. 输入框和提交按钮靠近操作区域。
5. 长公式需要允许局部滚动。
6. 解析区域默认折叠或按需展开。

## 后续数学输入体验

第一版先用普通文本输入。

后续应根据题型提供输入组件：

| 题型 | 输入方式 |
| --- | --- |
| 数值题 | 数字键盘 |
| 方程解 | 解集合输入组件 |
| 分数 | 分数输入组件 |
| 几何角 | 符号选择 |
| 函数解析式 | 表达式输入 |
| 多步题 | 分步输入 |
