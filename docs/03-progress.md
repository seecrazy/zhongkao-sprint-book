# 项目进展

最后更新：2026-11-01。当前阶段：v0.12 完成，五学科全部上线

## 当前摘要

v0.12 接入英语和语文试点，五学科（数学 / 物理 / 化学 / 英语 / 语文）全部上线。英语覆盖语法、词汇与书面交际（听力暂缺）；语文覆盖积累运用类客观题（作文与阅读主观题暂缺）。

v0.11 对物理和化学同步扩容：两学科各从 5 考点扩展到 8 考点，各新增 3 道压轴题（物理含过桥、柱体压强、并联分流模型，化学含方程式计算、溶液稀释、电解水计算），并各新增 1 套综合挑战卷；全库题量突破 100 题，物理化学均具备完整难度分层。

v0.10 借助多学科架构快速接入化学试点：5 个考点、15 道题、2 套卷，内容校验一次通过；多学科体系扩展到三个学科。

v0.9 完成多学科架构改造：路由按学科分前缀、存储按学科分键、导航新增学科切换器；同时接入物理试点内容（5 考点、15 题、2 卷），学习闭环完整复用到第二个学科。

v0.8 补齐了几何压轴层级：新增 6 道难度 4 的几何题，分别对应平行线拐点、菱形面积双算、平行弦垂径、勾股完全平方、母子相似和坐标变换链 6 个中考经典模型；压轴挑战卷几何分区同步扩展到 6 题。

v0.7 执行了几何扩展计划，新增相交线与平行线、四边形、圆、直角三角形与勾股定理、图形变换 5 个考点，每个考点都带有完整结构化讲解和 3 道分层练习题；同时新增几何基础专项卷，几何体系从 3 个考点扩展到 8 个。

v0.5 在 v0.4 的每日计划和基础模考上继续推进，把模考升级为分区组卷，新增 3 套试卷和得分率趋势图；掌握度模型加入时间衰减、难度调整和近期练习量；同时引入 Vitest，建立 11 个核心业务规则测试。

v0.6 补齐了此前“考点只有题、没有系统讲解”的缺口。现在每个考点都有学习目标、核心思路、概念讲解、核心公式、例题、易错警示和解题策略，并且可以从考点卡片直接进入对应专题练习。

当前闭环：

```text
每日计划
→ 考点讲解
→ 薄弱考点专项
→ 到期错题复习
→ 分区限时模考
→ 总分 / 分区 / 分考点报告
→ 加权掌握度与趋势更新
→ 下一步冲刺建议
```

## 已知技术债

1. 仍未支持多步题和过程分。
2. 表达式判分仍不是完整表达式等价判断。
3. 掌握度难度调整是线性近似，还不是标准 IRT 或题目难度校准。
4. 模考逐题用时按整卷平均估算。
5. 内容缺少运行时 Schema 校验。
6. KaTeX 全量字体使构建产物偏大。
