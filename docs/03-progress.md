# 项目进展

最后更新：2026-10-31  
当前阶段：v0.4 数学试点完成，每日冲刺计划与限时模考基础版已接入

## 当前摘要

v0.4 已完成本地开发。项目在 v0.3 的掌握度和错题复习基础上，新增了每日冲刺计划、限时模考、答题卡、自动交卷、分考点报告和最近成绩历史。数学题库也从 19 道扩展到 25 道，覆盖率报告中 11 个考点全部达到结构健康。

当前闭环：

```text
生成今日任务
→ 薄弱考点专项 / 到期错题复习
→ 限时模考
→ 自动判分与分考点报告
→ 记录尝试、错题和用时
→ 更新掌握度
→ 生成下一次复习与冲刺建议
```

## 已知技术债

1. 掌握度仍是简化加权模型，没有时间衰减和难度权重。
2. 表达式判分还不是完整数学表达式等价判断。
3. 模考还不是标准中考分区卷。
4. 模考平均用时按整卷用时平均到每题，不是逐题精确计时。
5. 内容 JSON 仍使用 TypeScript 类型断言，缺少运行时 Schema 校验。
6. KaTeX 全量字体导致构建产物偏大。
