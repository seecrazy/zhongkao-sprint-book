## 已知技术债

1. 仍未支持多步题和过程分。
2. 表达式判分仍不是完整表达式等价判断。
3. 掌握度难度调整是线性近似，还不是标准 IRT 或题目难度校准。
4. 模考逐题用时按整卷平均估算。
5. 内容缺少运行时 Schema 校验。
6. KaTeX 全量字体使构建产物偏大。
